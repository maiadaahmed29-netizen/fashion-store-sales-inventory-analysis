# Fashion Store Sales & Inventory Analysis

## Project Overview

This project presents an end-to-end analysis of a fashion e-commerce store covering sales, orders, product categories, inventory performance, distribution centers, and future inventory demand.

## Key Results

- Total Sales: $10.83M
- Total Profit: $5.62M
- Profit Margin: 51.90%
- Total Orders: 125,226
- Sales per Order: $86.46
- Top Category: Outerwear & Coats
- Best-Selling Product: The North Face Apex Bionic Jacket
- Top Distribution Center: Houston, TX
- Peak Sales Month: January 2024
- YoY Sales Growth: 187.64%
- Forecasted Demand: 14,905 items
- Reorder Required: No
